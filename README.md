# Lukx Web

Clon del sitio [lukx.com.mx](https://lukx.com.mx/) en Next.js (App Router) + Tailwind CSS.

## Desarrollo

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — servidor de desarrollo
- `npm run build` — build de producción
- `npm start` — servir build

## Estructura

- `src/app/` — rutas (home, soluciones, blog, portfolio, contacto, FAQs)
- `src/components/` — header, footer, home sections, UI compartida
- `src/data/` — contenido en español del sitio
- `public/images/` — logos e imágenes descargadas del sitio original
